Kurulumu tamamlamak (admin hesabını oluşturmak) için şu linki açın:

https://__DOMAIN__/setup?token=__SETUP_TOKEN__

Bu link tek kullanımlıktır ve yalnızca size gösterilir: anahtarı bilmeyen biri admin hesabı oluşturamaz.
Kaybederseniz sunucuda `sudo yunohost app setting __APP__ setup_token` ile görebilirsiniz.
