# Hızlı Başlangıç

Kendi bilgisayarınızda birkaç dakikada denemek için (Docker gerekir):

```bash
git clone https://github.com/rraeyz/kunye_ynh.git linktree
cd linktree
./start.sh
```

1. `http://localhost:3000/setup` adresini açın, admin şifrenizi ve profilinizi oluşturun.
2. `http://localhost:3000/admin` panelinden linklerinizi, temanızı ve profil fotoğrafınızı ekleyin.
3. `http://localhost:3000` sizin sayfanız.

Sunucuya kurmak için:
- YunoHost: [YUNOHOST-KURULUM.md](YUNOHOST-KURULUM.md)
- Docker: [DOCKER-KURULUM.md](DOCKER-KURULUM.md)

Docker olmadan geliştirme ortamı kurmak için [README.md](README.md#geliştirme) dosyasına bakın.
